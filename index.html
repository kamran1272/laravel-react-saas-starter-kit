What's inside

Every feature below exists in the kit, works out of the box, and is covered by the setup docs. No stubs, no placeholder code.

Backend — Laravel 11 API

  • Sanctum token authentication — register, login, logout, and "me" endpoints
  • Role-based access control (admin / user) via a reusable role middleware
  • Full Users CRUD API (admin only) — pagination, validation, self-delete protection
  • Dashboard stats endpoint with real database-computed metrics
  • JSON-first API — clean 401/403/404/422 JSON responses everywhere
  • Pre-seeded database — the demo works out of the box, zero config
  • 10 passing feature tests covering the auth flow
  • .env.example and organized, readable codebase

Frontend — React 18 + Vite

  • Login / Register pages with per-field validation errors
  • Auth context with token persistence and automatic session restore
  • Protected routes plus admin-only routes
  • Dashboard layout — dark sidebar, topbar, 4 stat cards, recent-users table
  • Admin Users page — full CRUD with modals, role management, pagination
  • Axios API client with Bearer injection and 401 auto-logout
  • Tailwind CSS styling, ready to theme
